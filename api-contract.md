# API Contract

## 1. Deskripsi Sistem

API Contract ini menjelaskan aturan komunikasi antara client dan server pada sistem prediksi jumlah pengunjung Wisata Religi Makam Gus Dur.

Sistem digunakan untuk melakukan prediksi jumlah pengunjung berdasarkan hari kunjungan menggunakan algoritma XGBoost dengan optimasi Grid Search.

API berfungsi sebagai penghubung antara frontend website dengan backend prediction service.
